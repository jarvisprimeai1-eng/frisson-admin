# Frisson Admin — Setup Guide

Привет, Анастасия! Вот что нужно сделать, чтобы запустить админ-панель. Всего 3 шага, ~10 минут.

## Шаг 1. Настроить базу данных в Supabase

1. Открой свой [Supabase dashboard](https://supabase.com/dashboard)
2. Выбери проект Frisson
3. В левом меню нажми **SQL Editor** → **New query**
4. Открой файл `supabase/schema.sql` в этой папке — **скопируй весь текст** и **вставь в редактор** в Supabase
5. Нажми **Run** (или Ctrl+Enter)
6. Должно появиться "Success. No rows returned"

Теперь настрой Storage (для загрузки аудио):

7. Снова **New query** → скопируй и запусти `supabase/storage-setup.sql`

## Шаг 2. Создать аккаунт администратора

1. Открой [`frisson-admin.vercel.app`](https://frisson-admin.vercel.app) (ссылка будет после деплоя)
2. Нажми "Создать аккаунт"
3. Email: `anastasiyazvanok@gmail.com`
4. Пароль: придумай надёжный (не храни его в мессенджерах)
5. Проверь почту — кликни на ссылку подтверждения от Supabase

## Шаг 3. Дать себе права админа

После регистрации — ты обычный пользователь. Нужно один раз пометить тебя как админа:

1. Вернись в Supabase → **SQL Editor** → **New query**
2. Вставь и запусти `supabase/make-admin.sql`
3. Должно показать твой email с `is_admin: true`

Теперь перезагрузи админ-панель — увидишь полный интерфейс. ✨

## Как пользоваться

### Загрузка медитации
1. Открой **Медитации** в левом меню
2. Нажми **+ Новая медитация**
3. Заполни:
   - Название
   - Краткое описание (одно предложение)
   - Раздел (Ресурс / Женское / и т.д.)
   - Иконка — эмодзи или символ (✦ ◦ ◈ 🌸)
4. Загрузи MP3 — длительность определится автоматически
5. Галочки:
   - **Премиум** — доступна только по подписке
   - **Активна** — видна пользователям (если хочешь сначала как черновик — сними галочку)
6. Нажми **Опубликовать**

Готово — в течение 5 секунд медитация появится у всех пользователей приложения.

### Редактирование
Просто кликни на медитацию в списке — откроется редактор.

### Удаление
В редакторе внизу слева — красная кнопка **Удалить**. Это необратимо.
